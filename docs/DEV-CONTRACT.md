# BAT RUNNING XR 自主開發契約
1. 使用者只提出需求、提供必要的帳號/裝置授權、安裝或體驗完成品。程式、場景、SDK、CI、簽章、錯誤修復及打包皆為開發端責任。
2. 原始網站保持獨立可運作；禁止修改無關 repo。
3. 版本任務以完整驗收及交付為目標，不以建立檔案、提交程式、規劃或靜態檢查冒充 APK 產出。遇阻先排查、修復、重跑。
4. CI 必須雙 APK 皆成功、headless smoke 通過、APK arm64/loader/資產/簽章檢查通過，保存日誌與 SHA256。標示 debug 或 release；正式版使用持久安全簽章。
5. 分別在 Quest 3、Focus 3 確認安裝、啟動、沉浸式雙眼畫面、轉頭及雙控制器、追蹤中斷與恢復。未實測不得聲稱相容性保證。
6. XR-000 無強制移動，不需要真實跑跳。遵守原廠年齡及安全規範；禁止原始追蹤資料上傳。
7. 使用者不應經手安裝引擎、SDK、Gradle 或修改設定。只提出必要帳號授權。
