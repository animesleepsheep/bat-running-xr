# APK update contract
Package IDs: com.pottersheep.batrunning.xr.quest3 and com.pottersheep.batrunning.xr.focus3. XR001 versionCode=2, versionName=0.1.0. Future versions strictly increase versionCode; do not rename package IDs. Android requires same signing identity and higher version for update. XR000 used an ephemeral debug key; first stable build may require one uninstall (local data lost).
Release workflow dispatch signing=release uses protected repository secrets XR_KEYSTORE_B64, XR_KEY_ALIAS, XR_KEY_PASSWORD (same keystore/key password for Godot), public repo variable XR_CERT_SHA256. The signer fingerprint is verified on both APKs; missing secret or mismatch fails the job. Keep signing key in protected storage outside repository and public artifact/cache; only trusted branch runs may use it. Never publish key or password. Debug build is not a persistent upgrade channel. Do not treat app install or controller compatibility as verified until real headset tests.
